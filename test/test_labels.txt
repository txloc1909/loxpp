# Consumer labels of every CTest test (issue #1258).
#
# One line per test: <name> <label>[,<label>...]. <name> is a GTest target
# listed in LOXPP_GTEST_TARGETS, or the name of an add_test() test. test/
# CMakeLists.txt gives each test its labels, so CI can run `ctest -L <label>`.
# tools/check_test_labels.py fails when a test has no line here, when a line
# names no test, or when a label is not in the list below.
#
# A test has the label of each consumer it can fail for:
#   core            the native VM, the compiler, the scanner, the stdlib
#   shared-backend  an analysis pass that both backends use
#   jvm             the JVM backend
#   qbe             the QBE backend
#   tooling         the resolver, the parser for tools, the language server
#   bootstrap       the bootstrap interpreter
#   harness         a differential or probe tool (tools/diff_runtimes.py, ...)
#   corpus          also reads programs under examples/, bootstrap/ or test/
#   bench           reads or checks something under benchmarks/
