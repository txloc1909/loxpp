# Spec probes that the bootstrap interpreter does not pass yet.
#
# One line per spec probe of test/translation-probes/ that the bootstrap
# interpreter does not pass yet: the file name, then a reason that names the
# issue of the node that makes it pass. Blank lines and lines that start with
# '#' are comments.
#
# tools/check_spec_probes.py and tools/diff_runtimes.py read this file with
# --xfail.
#
# A listed probe must fail. A listed probe that passes fails the gate until
# its line is deleted, so the node that makes a probe pass deletes the line.
# A name with no spec probe behind it is an error.
